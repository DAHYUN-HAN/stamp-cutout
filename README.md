# stamp-cutout

사진 한 장을 우표 모양으로 오려내 위·아래 두 폭으로 구성한 이미지를 만드는 웹 도구.

**→ https://dahyun-han.github.io/stamp-cutout/**

아래 칸에는 사진에서 우표 모양이 실제로 뚫려 종이 배경이 비쳐 보이고,
위 칸에는 그 오려낸 조각이 **같은 자리**에 놓인다.

## 쓰는 법

| | |
|---|---|
| 사진 업로드 | 사진을 골라 아래 칸을 꽉 채우도록 배치 |
| 우표 끌기 | 구멍 위치 이동 — 위 칸 조각도 같이 움직인다 |
| 빈 곳 끌기 | 사진 이동 |
| 두 손가락 · 휠 | 사진 확대 |
| 우표 위치 초기화 | 우표만 처음 자리로 (사진 상태는 유지) |
| 저장 | JPG로 내려받기 |

## 규격

- 출력 `1560 × 2080` (3:4). 위·아래 칸 각 `1560 × 1040`
- 우표 `498 × 360` 고정
- 톱니는 이미지가 아니라 경로로 그린다. `우표.svg` 의 비율을 그대로 따름 —
  234 단위 기준으로 반지름 10, 톱니 간격 25, 모서리 여백 17

## 파일

```
index.html    전부 여기에 들어 있다 (배경지 이미지도 내장, 외부 의존 없음)
og.jpg        링크 미리보기 원본 1200×630
og-<해시>.jpg  실제로 걸리는 미리보기 이미지. build.py 가 og.jpg 내용에서
              이름을 만든다 — 그림이 바뀌면 주소도 바뀌어서 카카오톡 등이
              예전 그림을 계속 쓰는 일이 없다
배경.jpg      종이 배경 원본
우표.svg      우표 모양 원본 — 톱니 비율의 출처
```

`index.html` 하나만 있으면 어디서든 돌아간다. 파일을 그대로 열어도 되고, 정적 호스팅에 올려도 된다.
